## 1. Параллельный мини-язык программирования

Создан интерпретатор мини-языка с поддержкой команд:

| Команда | Описание |
|---------|----------|
| `print <текст>` | Вывод в консоль |
| `save <файл> <текст>` | Запись в файл |
| `math <a> <op> <b>` | Арифметика (+, -, *, /) |
| `for <N> { ... }` | Цикл (вложенность команд) |

### Реализация

- **ООП:** все команды наследуются от базового класса `Cmd` (полиморфизм)
- **Парсер:** функция `parse()` разбирает строку в вектор команд
- **Параллельность:** каждая строка выполняется в отдельном потоке (`std::thread`)
- **Синхронизация:** `mutex` для безопасного вывода в консоль
